## 목적
위치 권한 상태 확인·변경, 정보 출처와 약관 안내, 오류 제보. 계정 항목 없음(M1 가입 없음).

## 레이아웃 (위→아래)
1. **상단 바**: 큰 제목 **설정**
2. **위치** 그룹 (그룹 제목 `type.caption` `text.secondary`, 좌우 20, 위 `space.6`)
   - 행 **위치 권한** / 오른쪽 값 `type.body` `text.secondary`: **허용됨** · **대략적 위치만** · **허용 안 됨** + `chevron.right` → 시스템 앱 설정
3. **정보** 그룹
   - **정보 출처** → 출처 목록 화면(한국관광공사 TourAPI, KOPIS 공연예술통합전산망, 서울 열린데이터광장, 문화공공데이터광장, 산림청·기상청 — 각 행에 링크 `arrow.up.right`). 하단 안내 `type.caption`: **요약은 AI(OpenAI GPT)가 원문을 정리한 것이에요. 정확한 내용은 원문을 확인해 주세요.**
   - **이용약관** → 인앱 브라우저
   - **개인정보 처리방침** → 인앱 브라우저
4. **도움** 그룹
   - **정보 오류 제보** → 메일 작성(받는 사람 `help@herezi.com` — 도메인 구매 후 확정, 제목 `[정보 오류]`, 본문에 앱 버전·OS)
5. **앱 버전** 행: 값 **1.0.0 (12)**, 탭 동작 없음
6. 맨 아래 로고(두리번 32) + `type.caption` `text.tertiary` **지금 내 주변, 히어지**

행 모양: 높이 56, 좌우 20, 제목 `type.body`, 구분선 없음(그룹 사이 여백만). iOS는 `List(.insetGrouped)` 대신 평평한 흰 목록으로 맞춘다.
