## 목적
계정(로그인 상태·로그아웃·회원 탈퇴), 위치 권한 상태 확인·변경, 정보 출처와 약관 안내, 오류 제보. **회원 탈퇴는 앱 안에서 끝까지 할 수 있어야 한다**(App Store 심사 지침 5.1.1(v)).

## 레이아웃 (위→아래)
1. **상단 바**: 큰 제목 **설정**
2. **계정** 그룹 (맨 위. 그룹 제목 `type.caption` `text.secondary`, 좌우 20, 위 `space.6`)
   - **로그인 전**: 행 **로그인** + `chevron.right` → S7 시트(제목 "로그인하고 저장한 볼거리를 모아 보세요"). 행 아래 보조 줄 없음.
   - **로그인 후** (3행):
     1. 계정 행 `AccountRow` — 제공자 표시 28 + **카카오로 로그인됨** / **Apple로 로그인됨**. 화살표 없음, 탭 동작 없음.
     2. **로그아웃** + `chevron.right`
     3. **회원 탈퇴** (`text.secondary` 글자) + `chevron.right` → 탈퇴 확인 화면 push
   - 이메일·닉네임은 보여주지 않는다(받지 않음 — TECH-PLAN §4.1 개인정보).
3. **위치** 그룹
   - 행 **위치 권한** / 오른쪽 값 `type.body` `text.secondary`: **허용됨** · **대략적 위치만** · **허용 안 됨** + `chevron.right` → 시스템 앱 설정
4. **정보** 그룹
   - **정보 출처** → 출처 목록 화면(한국관광공사 TourAPI, KOPIS 공연예술통합전산망, 서울 열린데이터광장, 문화공공데이터광장, 산림청·기상청 — 각 행에 링크 `arrow.up.right`). 하단 안내 `type.caption`: **요약은 AI(OpenAI GPT)가 원문을 정리한 것이에요. 정확한 내용은 원문을 확인해 주세요.**
   - **이용약관** → 인앱 브라우저
   - **개인정보 처리방침** → 인앱 브라우저
   - **오픈소스 라이선스** → 라이선스 화면 (현재 코드와 같음)
5. **도움** 그룹
   - **정보 오류 제보** → 메일 작성(받는 사람 `help@herezi.com` — 도메인 구매 후 확정, 제목 `[정보 오류]`, 본문에 앱 버전·OS)
6. **앱 버전** 행: 값 **1.0.0 (12)**, 탭 동작 없음
7. 맨 아래 로고(두리번 32) + `type.caption` `text.tertiary` **지금 내 주변, 히어지**

행 모양: 높이 56, 좌우 20, 제목 `type.body`, 구분선 없음(그룹 사이 여백 `space.8`만). iOS는 `List(.insetGrouped)` 대신 평평한 흰 목록으로 맞춘다.

## 로그아웃
1. **로그아웃** 행 → 확인 대화상자(시스템 알림, iOS `.alert` / Android `AlertDialog`)
   - 제목 **로그아웃할까요?**
   - 본문 **다시 로그인하면 저장한 볼거리를 그대로 볼 수 있어요.**
   - 버튼 **로그아웃** · **취소** (로그아웃은 파괴 동작이 아니므로 기본 스타일)
2. 확인 → Supabase 세션·저장 목록 캐시 삭제, 카카오 SDK `logout`. 서버 호출 실패해도 기기에서는 로그아웃 처리.
3. 설정 화면에 머문 채 계정 그룹이 **로그인** 행으로 바뀌고 토스트 **로그아웃했어요**. S4는 로그인 전 상태.

## 회원 탈퇴 흐름

### 1) 탈퇴 확인 화면 (push, `DestructiveConfirm`)
목업 오른쪽.
1. 상단 바: 뒤로만(제목 없음).
2. 제목 `type.title1` 두 줄: **탈퇴하기 전에** / **확인해 주세요** (좌우 20, 위 `space.6`)
3. **지워지는 것** 박스 (위 `space.8`, `bg.secondary`, `radius.md`, 안쪽 위아래 12·좌우 16, 행 높이 48, 아이콘 22 `text.secondary` + `type.bodyStrong`)
   - `bookmark`: **저장한 볼거리 N개가 모두 지워져요** (N = 현재 저장 수. 0이면 **저장한 볼거리가 모두 지워져요**)
   - `person.crop.circle.badge.xmark` / `link_off`: **카카오 계정 연결이 끊어져요** / **Apple 계정 연결이 끊어져요**
   - `exclamationmark.circle` / `error_outline`: **지운 정보는 되돌릴 수 없어요**
4. 안내 `type.caption` `text.secondary` (박스 아래 `space.3`): **같은 계정으로 다시 가입할 수 있지만, 저장한 볼거리는 돌아오지 않아요.**
5. 확인 체크 (위 `space.6`): 체크박스 24(`radius.xs`, 꺼짐 = 테두리 `gray200` 2 / 켜짐 = 잉크 + 흰 체크) + `type.bodyStrong` **위 내용을 확인했어요**. 줄 전체가 터치 영역.
6. **하단 고정 바** (S3과 같은 모양, 위 1px `border`): 주 버튼 **탈퇴하기** — 체크 전에는 비활성(`gray200` 배경·`gray500` 글자), 체크 후 활성(잉크).

### 2) 최종 확인 (시스템 파괴 대화상자)
**탈퇴하기** → 시스템 알림
- 제목 **정말 탈퇴할까요?**
- 본문 **저장한 볼거리와 계정 정보가 바로 지워져요.**
- 버튼 **탈퇴** (iOS `role: .destructive` → 시스템 빨강 / Android `TextButton` 글자 `color.status.error`) · **취소**
- 빨강은 이 시스템 대화상자 버튼에만 쓴다. 탈퇴 화면의 주 버튼은 잉크다(앱 안에 빨강 넓은 면을 만들지 않는다).

### 3) 진행 중
- **탈퇴하기** 버튼 글자 자리에 진행 표시(흰색 20), 뒤로·체크 비활성, 스와이프 뒤로 막음.
- 서버 `DELETE /v1/me`(저장 삭제 + Supabase 사용자 삭제). 카카오는 앱에서 `unlink`, Apple은 서버가 토큰 철회(아래 주의).

### 4) 완료 화면
탈퇴 확인 화면을 **완료 화면으로 교체**(뒤로 가기로 돌아갈 수 없음, 상단 바 없음).
- 가운데 정렬, 위 `space.10`: 아이콘 `checkmark.circle` / `check_circle` 48 `icon.primary`
- 제목 `type.title2` **탈퇴했어요**
- 설명 `type.body` `text.secondary` **그동안 히어지를 써 주셔서 고마워요.**
- 하단 주 버튼 **확인** → 탭 바를 처음 상태로 되돌리고 **주변 탭 홈(S1)** 으로. 로그인 전 상태.
- 기기의 세션·캐시·기기 로컬 저장을 모두 지운다.

### 5) 실패
- 진행 표시 해제, 확인 화면 그대로(체크 유지). 토스트 **탈퇴하지 못했어요. 잠시 후 다시 시도해 주세요.**
- 네트워크 없음이면 **인터넷 연결을 확인하고 다시 시도해 주세요.**
- 세션 만료로 실패하면 S7 시트를 띄워 다시 로그인하게 하고, 로그인 후 이 화면으로 돌아온다(대기 동작 = 없음, 사용자가 다시 **탈퇴하기**).

## 상태
| 상태 | 모습 |
|---|---|
| 로그인 전 | 계정 그룹에 **로그인** 행 하나 |
| 로그인 후 | 계정 그룹 3행(계정·로그아웃·회원 탈퇴) |
| 로그인 직후(S7에서 돌아옴) | 계정 그룹이 바로 로그인 후 모양으로, 토스트 **로그인했어요** |
| 위치 권한 바뀜 | 앱이 포그라운드로 돌아올 때 값 갱신 |
| 메일 앱 없음 | 토스트 **메일 앱이 없어요. help@herezi.com 으로 보내 주세요** (주소는 도메인 구매 후 확정 — DESIGN §9) |

## 접근성
- 각 행 "위치 권한, 허용됨, 버튼". 외부로 나가는 행은 힌트 "설정 앱이 열려요" / "브라우저가 열려요".
- 계정 행: "카카오로 로그인됨" (버튼 아님, 정적 텍스트). 로그인 행: "로그인, 버튼, 로그인 창이 열려요".
- 회원 탈퇴 행: "회원 탈퇴, 버튼". 탈퇴 확인 화면: 제목 → 지워지는 것 3줄 → 안내 → 체크박스("위 내용을 확인했어요, 체크박스, 선택 안 됨") → 버튼("탈퇴하기, 흐리게 표시됨").
- 완료 화면이 뜨면 초점을 제목으로.
- `회원 탈퇴`를 `text.secondary`로 두는 건 위계만 낮추는 것 — 대비 7.1:1로 충분.

## 개발자 주의
- **Apple 탈퇴 = 토큰 철회 필수**(Apple 가이드: 계정 삭제 시 Sign in with Apple 토큰 revoke). 서버가 `appleid.apple.com/auth/revoke`를 부르려면 로그인 때 받은 authorization code로 만든 refresh token이 서버에 있어야 한다. 없다면 탈퇴 직전 iOS에서 Apple 재인증으로 새 authorization code를 받아 `DELETE /v1/me`에 함께 보낸다. (서버 이슈로 따로 정리)
- 카카오 탈퇴 = 앱에서 `UserApi.unlink` 후 서버 `DELETE /v1/me`. unlink 실패해도 서버 삭제는 진행.
- 탈퇴 후 같은 계정으로 다시 로그인하면 새 사용자(빈 저장 목록).
