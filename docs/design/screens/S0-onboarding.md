# S0 스플래시 · 위치 권한 안내

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN §9 S0, §12 Q4

## 목적
왜 위치가 필요한지 한 문장으로 알리고, 시스템 권한 창을 띄우기 전에 마음의 준비를 시킨다. 거부해도 바로 홈(서울시청 기준)으로 간다. **가입·입력 없음.**

## 언제 보이나
- 앱 첫 실행, 그리고 위치 권한이 "한 번도 묻지 않음" 상태일 때만.
- 이미 허용 / 이미 거부 상태면 S0을 건너뛰고 스플래시 후 S1로 바로 간다.

## 레이아웃 (위→아래)
1. **스플래시** (시스템 런치 스크린): 흰 배경 가운데 로고(두리번, 88×88). 글자 없음. 최대 1초.
2. **권한 안내** (흰 배경, 좌우 20)
   - 상단 안전 영역 아래 `space.10`: 로고 56×56
   - `space.6` 아래 제목 `type.display`, 2줄:
     **지금 내 주변에 뭐가 있는지**
     **바로 보여드릴게요**
   - `space.3` 아래 설명 `type.body` `text.secondary`:
     축제, 공연, 전시, 팝업, 벚꽃 명소까지 — 위치만 허용하면 가입 없이 바로 볼 수 있어요.
   - 가운데 여백(유연)에 카테고리 아이콘 9개를 3×3 원(지름 56, 카테고리 색 12% 배경 + 카테고리 아이콘 24)으로 배치. 장식용, 스크린리더에서 숨김.
   - 하단 고정 (안전 영역 위 `space.4`):
     - 주 버튼 **위치 허용하기**
     - `space.2` 아래 글자 버튼 **나중에 할게요**
     - `space.2` 아래 `type.caption` `text.secondary` 가운데: 위치는 주변 볼거리를 찾는 데만 써요.

## 상태
| 상태 | 모습 |
|---|---|
| 기본 | 위 레이아웃 |
| 시스템 권한 창 표시 중 | 화면 그대로(뒤에 깔림) |
| 허용 | S1으로 이동(교차 페이드 `motion.base`), 내 위치 기준 조회 |
| 거부 / 나중에 | S1으로 이동, 서울시청(37.5663, 126.9779) 기준, 위치 꺼짐 배너 표시 |

## 시스템 권한 문구
- iOS `NSLocationWhenInUseUsageDescription`: **지금 내 주변의 축제·공연·전시를 보여드리기 위해 위치를 사용해요.**
- 요청 권한: iOS "앱을 사용하는 동안", Android `ACCESS_COARSE_LOCATION` + `ACCESS_FINE_LOCATION` (대략적 위치만 허용돼도 정상 동작).

## 인터랙션
- **위치 허용하기** → 시스템 권한 창. 결과와 관계없이 S1으로.
- **나중에 할게요** → 권한 창을 띄우지 않고 S1으로. 다음 실행 때 S0을 다시 보여주지 않는다(배너의 `허용하기`로 언제든 요청).
- Android 뒤로가기 → 앱 종료.

## 접근성
- 제목은 헤더(`.isHeader` / `heading()`), 두 줄을 한 문장으로 읽는다.
- 3×3 아이콘 그림은 장식(`accessibilityHidden(true)` / `clearAndSetSemantics {}`).
- 다이나믹 타입 최대에서 아이콘 그림은 숨기고 문장·버튼만 스크롤 영역에 둔다.
