# S2 지도

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN §8 P0 지도 보기, §9 S2, 시나리오 4 · 목업: [../mockups/map.png](../mockups/map.png)
> 진입: 하단 **지도 탭**, 또는 S1b의 **지도로 보기**(필터를 넘겨받음) — DESIGN §6.12
> 코드: iOS `Features/Nearby/NearbyView.swift`(`NearbyMap`), `MapUI` · Android `feature/nearby`

## 목적
주변 볼거리를 지도 위 카테고리 핀으로 보여주고, 지도를 옮겨 다른 동네도 탐색하게 한다.

## 데이터 (v1.4, SERVICE-PLAN §12 Q8)
좌표·지도 영역을 서버로 보내지 않는다. 앱이 받아 둔 **지역 데이터 파일**(`GET /v1/regions/seoul/spots`)에서 기기가 고른다:
끝난 항목 제외 → 보이는 영역(bbox) 안 → `when`·`category`·`free` 필터 → 영역 중심에서 가까운 순 최대 200개. 클러스터링도 앱에서.
200개를 넘으면(이전의 `truncated: true`) 토스트로 확대를 권한다. 서버 `/v1/spots/map`은 쓰지 않는다(폐기 예정).
위치명은 기기 지오코더(iOS `CLGeocoder`, Android `Geocoder`).

## 레이아웃 (위→아래)
1. **네이버지도** 전체 화면(상태 표시줄 아래까지). 지도 기본 스타일, POI 라벨은 기본값 유지.
2. **상단 필터 영역** (흰 배경, 지도 위에 겹침, 아래 `elevation.1` 대신 1px `border`)
   - 상단 바: 위치명 + 검색 아이콘 (S1b와 같음, 뒤로 버튼 없음 — 탭 첫 화면)
   - 기간 탭 `WhenTabs`
   - 칩 줄 `CategoryChips`
3. **위치 꺼짐 배너** (권한 없을 때, 필터 영역 바로 아래, 지도 위에 떠 있음, `elevation.1`)
4. **이 지역에서 다시 찾기** `FloatingPill`(흰 배경 변형, `arrow.clockwise` 아이콘) — 필터 영역 아래 12, 가운데. 지도를 사용자가 움직였을 때만 보인다.
5. **핀·클러스터** `MapPin` / `MapCluster`, 내 위치 점(잉크).
6. **내 위치 버튼**: 오른쪽, 시트 위 16. 흰 원 44, `elevation.1`, 아이콘 `location`(따라가는 중이면 `location.fill`).
7. **목록으로 보기** `FloatingPill`(`list.bullet`) — 시트 위 16, 가운데.
8. **바텀시트** `SpotSheet` — 접힘: **이 지역 볼거리 24개** / 핀 선택: SpotCard 1장 / 펼침: 목록.
9. **탭 바**: 주변 · 지도(선택) · 저장

## 상태
| 상태 | 모습 · 문구 |
|---|---|
| 첫 진입 | 내 위치(또는 서울시청) 중심, 반경 3km가 보이는 줌(약 14). 시트 접힘 |
| 로딩 | (기기 데이터가 없을 때만 — 첫 동기화) 기존 핀 유지, 시트 접힘 줄 문구 **찾는 중…**, "다시 찾기" 알약 안 아이콘이 회전(동작 줄이기 시 정지) |
| 데이터 있음 | 핀·클러스터, 시트 **이 지역 볼거리 N개** |
| 너무 많음 | 영역 안 결과 200개 초과 → 토스트 **볼거리가 많아요. 지도를 확대하면 더 보여요** (영역당 1회) |
| 빈 | 핀 없음, 시트 접힘 줄 **이 지역엔 지금 볼거리가 없어요** + 글자 버튼 **이번 주로 보기**(when≠week일 때) |
| 오류 | 기기에 지역 데이터가 없고 받지도 못함: 기존 핀 유지, 시트 접힘 줄 **불러오지 못했어요** + 글자 버튼 **다시 시도** |
| 위치 거부 | 서울시청 중심, 배너 표시, 내 위치 버튼 탭 시 배너의 `설정` 동작과 같음 |
| 지도 키 없음(개발 빌드) | 회색 배경 가운데 **지도를 불러오지 못했어요** + 목록으로 보기만 |

## 인터랙션
- **핀 탭** → 핀 확대·라벨, 시트가 카드 높이로 올라와 해당 SpotCard 표시. 카드 탭 → S3.
- **클러스터 탭** → 묶인 핀이 모두 보이게 확대(`motion.slow`).
- **빈 지도 탭** → 선택 해제, 시트 접힘.
- **지도 이동·확대** → 자동 재조회하지 않는다. "이 지역에서 다시 찾기" 알약 등장(`motion.base`). 탭하면 현재 보이는 bbox로 조회하고 알약 숨김.
- **필터 변경** → 현재 bbox로 즉시 재조회.
- **시트 위로 끌기** → 펼침: 현재 결과를 지도 중심에서 가까운 순으로 SpotCard 목록. 목록 카드 탭 → S3.
- **내 위치 버튼** → 내 위치로 이동 후 그 지역 재조회.
- **목록으로 보기** → 주변 탭으로 전환하고 S1b([S1b-list.md](S1b-list.md))를 지금 필터로 연다. S1b는 bbox가 아닌 **목록 기준 위치(내 위치 또는 시청)** 로 보여준다. 지도에서 다른 동네로 옮겨 다시 찾았다면 S1b도 그 지도 중심 기준으로 보여주고, 위치명은 지도 중심의 동 이름으로 바꾼다. 홈(S1)은 항상 내 위치(또는 시청) 기준이며 지도 이동에 따라 바뀌지 않는다.

## 접근성
- 지도는 스크린리더가 켜져 있으면 시트를 펼침 상태로 시작(목록이 대안).
- 핀 라벨 "공연, 세종 체임버 콘서트", 클러스터 "볼거리 12개, 두 번 탭하면 확대".
- "이 지역에서 다시 찾기"가 나타나면 스크린리더에 알리지 않는다(이동마다 시끄러움). 조회 완료 시 "이 지역 볼거리 24개" 알림.
