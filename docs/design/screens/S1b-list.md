# S1b 전체 목록 (근처 목록)

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN §8 P0 근처 목록·필터·위치 미허용 대응, §9 S1 · 홈: [S1-home.md](S1-home.md) · 목업: [../mockups/nearby-list.png](../mockups/nearby-list.png), [../mockups/location-denied.png](../mockups/location-denied.png)
> 코드: iOS `Features/Nearby/NearbyView.swift` · Android `feature/nearby/NearbyScreen.kt`

## 목적
홈(S1, 사진 카드 피드)에서 **전체 보기**·카테고리 아이콘을 누르면 들어오는 A안 클린 리스트. "지금 내 주변" 볼거리를 거리순으로 빠짐없이 보여주고, 기간·카테고리·무료 필터로 좁히며, 지도(S2)로 바꿔 볼 수 있다.

## 진입
주변 탭 안에서 홈 위로 push(iOS `NavigationStack`, Android 같은 탭의 백스택). 들어올 때 필터를 받아 시작한다.

| 진입 | 시작 필터 |
|---|---|
| 홈 카테고리 아이콘 `전체` | when=now, 카테고리 없음 |
| 홈 카테고리 아이콘(예: 공연) | when=now, category=performance |
| 섹션 **전체 보기** | 섹션별 — [S1-home.md](S1-home.md) "전체 보기 연결" 표 |
| 홈 맨 아래 **전체 목록 보기** | when=week |
| 지도(S2) **목록으로 보기** | 지도의 필터 그대로, 기준 위치 = 지도 중심 |

시작 필터에서 결과가 0개면 빈 상태를 그대로 보여준다(자동으로 기간을 늘리지 않는다).

## 데이터
`GET /v1/spots?lat&lng&radius_m=3000&when&category&free&limit=30` → 거리순. `next_cursor`가 있으면 끝에서 5개 남았을 때 다음 페이지.

## 레이아웃 (위→아래)
1. **상단 바** (높이 56, 좌우 20, 스크롤해도 고정, 흰 배경)
   - 왼쪽: 뒤로 버튼(`chevron.backward` / `arrow_back`, 터치 44/48) → 홈. 그 오른쪽에 현재 위치명 `type.title2` (예: **중구 태평로1가**). 위치 거부 시 **서울시청 주변**. 역지오코딩 실패 시 **내 주변**.
   - 오른쪽: 검색 아이콘 버튼(→ S5).
2. **기간 탭** `WhenTabs`: 지금 · 오늘 · 이번 주말 · 이번 주 (좌우 20, 높이 44)
3. **칩 줄** `CategoryChips` (위 `space.2`, 아래 `space.3`): `무료만 │ 전체 · 자연·계절 · 축제·행사 · 공연 · 전시 · 팝업 · 먹거리 · 아이·가족 · 반려동물 · 스포츠`
   - 1–3은 스크롤하면 위로 같이 밀려 올라가고, 칩 줄만 상단 바 아래에 붙는다(sticky). 붙은 상태에서 아래쪽 1px `border` 선.
4. **위치 꺼짐 배너** `LocationBanner` (권한 없을 때만, 칩 줄 아래 `space.3`)
5. **결과 수 줄** (좌우 20, 높이 36): `type.caption` `text.secondary` — **3km 안에 24개** (다음 페이지가 있으면 **3km 안에 30개 이상**)
6. **목록**: `SpotCard` 반복. 구분선 없음.
7. **목록 끝**: 다음 페이지 없으면 `type.caption` `text.tertiary` 가운데 **여기까지예요** (위아래 `space.6`)
8. **플로팅 알약** `FloatingPill` **지도로 보기** (`map` 아이콘), 탭바 위 16, 가운데. 아래로 스크롤할 때도 유지.
9. **탭 바**: 주변(선택) · 지도 · 저장

## 상태
| 상태 | 조건 | 모습 · 문구 |
|---|---|---|
| 위치 확인 중 | 권한 허용, 첫 위치 대기 (최대 5초) | 상단 위치명 자리에 스켈레톤 바(폭 120), 목록 스켈레톤 5장 |
| 로딩 | 첫 조회·필터 변경 | 목록 자리 스켈레톤 5장. 필터 변경 시 이전 목록 위에 덮지 않고 교체 |
| 데이터 있음 | items ≥ 1 | 위 레이아웃 |
| 빈 (필터 없음) | 기본 필터인데 0개 | 아이콘 `mappin.slash` · **근처에 지금 볼 만한 게 없어요** · 기간을 늘리거나 지도를 움직여 보세요. · 버튼 **이번 주로 보기**(when=week로 변경). when이 이미 week면 버튼 **지도로 보기** |
| 빈 (필터 있음) | 카테고리·무료·기간 중 하나라도 기본값이 아님 | **조건에 맞는 볼거리가 없어요** · 필터를 바꾸거나 기간을 늘려 보세요. · 버튼 **필터 초기화**(지금·전체·무료 끔) |
| 오류 | 네트워크·5xx | 아이콘 `wifi.exclamationmark` · **불러오지 못했어요** · 주변 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요. · 버튼 **다시 시도** |
| 다음 페이지 오류 | 추가 로딩 실패 | 목록 끝에 `type.caption` **더 불러오지 못했어요** + 글자 버튼 **다시 시도** |
| 위치 거부 | 권한 거부·나중에·위치 꺼짐·5초 초과 | 서울시청(37.5663, 126.9779) 기준 조회. 위치명 **서울시청 주변**, 배너 표시, 카드 거리는 시청 기준 |
| 새로고침 | 당겨서 새로고침 | 시스템 스피너, 완료 후 위치 다시 확인 |

빈·오류 상태에서도 상단 바·기간 탭·칩 줄·배너는 그대로 둔다(필터를 바로 바꿀 수 있게).

## 인터랙션
- 카드 탭 → S3 상세(push).
- 기간 탭·칩 변경 → 즉시 재조회(디바운스 300ms), 목록 맨 위로.
- **지도로 보기** → 지도 탭(S2)으로 전환하면서 지금 필터를 넘긴다(S2는 그 필터로 다시 조회). 주변 탭의 S1b는 백스택에 남는다.
- **뒤로**(버튼·스와이프·Android 뒤로) → 홈. 홈은 다시 조회하지 않는다.
- 앱이 백그라운드에서 15분 넘게 있다 돌아오면 위치·목록을 다시 조회.
- 위치가 500m 넘게 바뀌면 상단에 토스트 대신 결과 수 줄 자리에 글자 버튼 **현재 위치로 다시 찾기** 노출(자동 재조회하지 않음 — 보던 목록이 바뀌지 않게).

## 접근성
- 상단 위치명은 헤더. 라벨 "현재 위치, 중구 태평로1가".
- 결과 수 줄은 조회 완료 시 스크린리더에 알림(`AccessibilityNotification.Announcement` / `liveRegion = Polite`): "3km 안에 볼거리 24개".
- 칩 줄은 가로 스크롤이지만 스크린리더는 순서대로 모든 칩에 접근 가능해야 한다.
- 플로팅 **지도로 보기**는 목록 마지막 카드 뒤 순서로 읽힌다.
