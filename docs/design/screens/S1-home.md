## 목적
앱을 열자마자 "지금 내 주변"을 **큰 사진으로 보여 가고 싶게** 만든다. 비교·필터는 S1b(전체 목록)에 맡기고, 홈은 고르기 쉬운 몇 묶음만 보여준다. 모든 섹션은 **서버 데이터에서 규칙으로만** 만든다(편집자가 고르는 큐레이션 없음).

## 데이터 — API 호출 1번
```
GET /v1/spots?lat&lng&radius_m=3000&when=week&limit=100
```
- `when=week`(지금 ~ 7일 뒤와 겹치는 항목)는 `now`·`today`·`weekend`를 모두 포함하는 상위 집합이다(`internal/domain/when.go`). 그래서 **한 번 받아 앱에서 나눈다.** 섹션마다 따로 부르지 않는다.
- 응답은 거리순. 항목이 100개를 넘으면(`next_cursor` 있음) 가까운 100개만으로 홈을 만든다. 다음 페이지는 받지 않는다(홈은 '전부'가 아니라 '고른 것'). 전부는 S1b에서.
- 모든 시각 계산은 **KST**. 기준 시각 `now`는 응답을 받은 순간의 기기 시각 하나로 고정해 모든 섹션에 같이 쓴다.
- 홈 진입 시 호출 수: **1** (+ 이미지). 카테고리·전체 보기를 누르면 S1b가 자기 호출을 한다.

### API 변경이 필요한가
**M1에는 필요 없다.** 현재 계약(`limit` 최대 100, `when=week`)만으로 모든 섹션을 만들 수 있다. 나중에 고려할 것(별도 이슈, 필수 아님):
1. `SpotPage.total`(필터에 맞는 전체 개수) — 100개를 넘는 곳에서 헤드라인 숫자를 정확히 쓰려고. 지금은 "N개 이상"으로 처리한다.
2. 이미지가 없는 항목이 많으면 수집 단계에서 `image_url` 채우기(TourAPI `firstimage` 등) — 앱 문제가 아니라 데이터 문제. 그 전까지는 타이포 포스터(DESIGN §6.16)로 버틴다.

## 섹션 규칙 (데이터만으로)
정의 (`s` = 항목, `end` = `ends_at` 없으면 무한대):
- **진행 중** = `starts_at ≤ now < end`
- **오늘 시작 예정** = `now < starts_at ≤ 오늘 23:59:59`
- **오늘 끝남** = 진행 중이고 `end ≤ 오늘 23:59:59`
- **이번 주말 창** = 서버 `weekend`와 같다: 오늘이 토·일이면 이번 토 00:00–일 23:59:59, 아니면 다가오는 토·일. 창 시작이 지났으면 `now`부터.

| 순서 | 섹션 제목 | 넣는 항목 | 정렬 | 최소 | 최대 | 모양 |
|---|---|---|---|---|---|---|
| 0 | **지금 가장 가까운 곳** | 진행 중인 항목 중 가장 가까운 1개. 없으면 오늘 시작 예정 중 가장 가까운 1개 → 제목을 **오늘 가장 가까운 곳**으로 | 거리 | 1 | 1 | 히어로 카드 |
| 1 | **오늘 끝나요** | 오늘 끝남 | `ends_at` 빠른 순, 같으면 거리 | 3 | 10 | 가로 카드 |
| 2 | **이번 주말 놓치면 아쉬운** | 이번 주말 창과 겹침 | 거리 | 3 | 10 | 가로 카드 |
| 3 | **무료로 즐기기** | `is_free == true` | 거리 | 3 | 10 | 가로 카드 |
| 4 | **계절 한정** | `category == nature` | 거리 | 3 | 10 | 가로 카드 |

- **최소보다 적으면 섹션을 통째로 숨긴다**(제목도). 빈 섹션 자리 문구는 없다.
- **중복 줄이기:** 위 순서대로 채운다. 히어로에 나온 항목은 다른 섹션에 넣지 않는다. 가로 섹션은 앞 섹션에 이미 나온 항목을 **뒤로 미룬다**(안 나온 항목 거리순 → 이미 나온 항목 거리순). 최소 개수는 미루기 전 전체 후보 수로 판단하므로, 중복 때문에 섹션이 숨는 일은 없다.
- 홈에 보일 섹션이 히어로 하나뿐이어도 그대로 보여준다(아래 '전체 목록 보기'로 이어짐).
- 섹션 순서는 고정한다(날마다 위치가 바뀌면 손이 헷갈린다). 숨김만 있다.

### 전체 보기 연결 (→ S1b 시작 필터)
| 섹션 | S1b 필터 | 비고 |
|---|---|---|
| 지금 가장 가까운 곳 | when=now (오늘 시작 예정으로 바뀐 경우 when=today) | |
| 오늘 끝나요 | when=today | S1b엔 '오늘 끝남' 필터가 없어 오늘 하는 것 전체가 나온다. 의도된 근사 |
| 이번 주말 놓치면 아쉬운 | when=weekend | |
| 무료로 즐기기 | when=week, free=true | |
| 계절 한정 | when=week, category=nature | |

## 레이아웃 (위→아래, 한 스크롤)
좌우 여백 20, 섹션 사이 `space.8`(32). 목업 기준 390pt 폭.

1. **상단 바** (높이 56, 스크롤하면 같이 올라감 — 큰 헤드라인과 한 덩어리)
   - 왼쪽: 위치 아이콘(`mappin`·채움 / `location_on`, 18, `text.secondary`) + 현재 위치명 `type.bodyStrong` `text.secondary` (예: **중구 태평로1가**). 위치 거부 시 **서울시청 주변**, 역지오코딩 실패 시 **내 주변**. 누르는 동작 없음(M1에 위치 바꾸기 없음 — 비교안의 `⌄`는 넣지 않는다).
   - 오른쪽: 검색 아이콘 버튼 → S5.
2. **헤드라인** `type.display`(26/36 Bold), 2줄, 위 `space.2`:
   - **지금 근처에 / 볼거리 {N}개 있어요** — N = 진행 중 항목 수.
   - `next_cursor`가 있으면 **볼거리 {N}개 이상 있어요**.
   - 진행 중이 0개이고 이번 주 항목은 있으면 **이번 주 근처에 / 볼거리 {M}개 있어요** (M = 받은 항목 수, `next_cursor` 있으면 "이상").
   - 위치 거부: **서울시청 주변에 / 볼거리 {N}개 있어요**.
3. **위치 꺼짐 배너** `LocationBanner` (권한 없을 때만, 위 `space.4`). 홈에서는 문구가 두 줄로 접힐 수 있다.
4. **카테고리 칩 줄** `CategoryChips` 홈 모드(DESIGN §6.2, 위 `space.5`, 높이 36): `전체 · 자연·계절 · 축제·행사 · 공연 · 전시 · 팝업 · 먹거리 · 아이·가족 · 반려동물 · 스포츠`. S1b와 같은 칩·같은 이름 — 아이콘 없이 카테고리 색 점 8. `전체`는 잉크 배경·흰 글자(선택 모양), 나머지는 `bg.secondary`·잉크 글자. `무료만` 없음. 가로 스크롤, 순서 고정, 항목 0개인 카테고리도 숨기지 않는다. (#33 잠정 A안 — 사용자가 다른 안을 고르면 이 항목만 바뀐다.)
5. **섹션 0** `SectionHeader` + `HeroCard`
6. **섹션 1–4** 각각 `SectionHeader` + `SpotTileRow`
7. **전체 목록 보기** `SecondaryButton`(높이 56, 좌우 20, 위 `space.8`) → S1b(when=week). 아래 `type.caption` `text.secondary` 가운데: **3km 안 볼거리를 거리순으로 모두 볼 수 있어요** (위 `space.2`, 아래 `space.8`).
8. **탭 바**: 주변(선택) · 지도 · 저장. 홈에는 플로팅 "지도로 보기"를 두지 않는다(지도 탭이 있으므로).

## 인터랙션
- **히어로·가로 카드 탭** → S3 상세(push). 목록의 Spot으로 먼저 그린다.
- **히어로 저장 버튼** → 즉시 토글 + 햅틱 + 토스트 **저장했어요** / **저장을 취소했어요**. 카드 탭과 겹치지 않게 터치 영역 44/48을 따로 잡는다. 가로 카드엔 저장 버튼이 없다(작아서 오탭) — 길게 누르기 메뉴 **저장**/**저장 취소**로 제공.
- **카테고리 칩 탭** → S1b(when=now, 그 카테고리 선택). `전체` → S1b(when=now). 홈의 칩은 선택 상태가 바뀌지 않는다(이동 버튼).
- **섹션 전체 보기** → S1b(위 연결 표).
- **가로 줄 스크롤**: 카드 단위 스냅(왼쪽 끝을 여백 20에 맞춤). 마지막 카드 뒤 여백 20.
- 앱이 백그라운드에서 15분 넘게 있다 돌아오면 재조회. 위치가 500m 넘게 바뀌면 헤드라인 아래 글자 버튼 **현재 위치로 다시 찾기**(자동 재조회 안 함 — S1b와 같은 규칙).
- 홈의 스크롤 위치·가로 줄 위치는 S1b·S3에서 돌아와도 유지한다.

## 접근성
- 위치명: "현재 위치, 중구 태평로1가". 헤드라인은 헤더, 한 문장으로 읽기: "지금 근처에 볼거리 24개 있어요". 조회 완료 시 이 문장을 알림(`Announcement` / `liveRegion = Polite`).
- 섹션 제목은 헤더(`.isHeader` / `heading()`) — VoiceOver 로터·TalkBack 제목 이동으로 섹션 사이를 건너뛸 수 있다. **전체 보기** 라벨은 "이번 주말 놓치면 아쉬운, 전체 보기"처럼 섹션 이름을 붙인다.
- 히어로: 카드 한 요소 "서울빛초롱축제, 오늘 17시 시작, 축제·행사, 350미터, 12월 14일까지, 무료". 저장 버튼은 별도 요소 "저장"/"저장 취소".
- 가로 줄: 줄 하나를 컨테이너로(iOS `accessibilityElement(children: .contain)`, Android `CollectionInfo(rowCount=1, columnCount=n)`), 스크린리더는 화면 밖 카드까지 순서대로 읽는다. 카드 라벨은 SpotCard 규칙과 같다.
- 카테고리 칩: 버튼 "공연"(토글 아님 — 홈에서는 이동). 색 점은 장식, 이름이 글자로 있다.
- 타이포 포스터·사진 위 그라데이션은 장식 — 이미지 라벨은 사진일 때만 "{title} 사진", 포스터면 숨김(히어로에서 포스터 제목이 보이는 유일한 제목이어도 카드 라벨에 제목이 있으므로 중복해 읽지 않는다).
- 히어로 흰 글자 대비: §6.13의 그라데이션 하한으로 어떤 사진 위에서도 4.5:1 이상.
- 다이나믹 타입: 헤드라인·제목이 커지면 히어로 높이가 글자에 맞춰 늘어난다(최소 200). AX 크기에서 가로 카드 폭 148→200, 카테고리 라벨은 한 줄 말줄임 대신 타일 열 폭을 넓힌다. 가로 스크롤은 유지.
- 동작 줄이기: 스냅 애니메이션 없이 즉시 이동.
