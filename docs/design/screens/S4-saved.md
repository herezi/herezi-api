# S4 저장 목록

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN v1.3 §8 P1 저장(찜)·계정, §9 S4, Q6·Q7 · 기술: TECH-PLAN §4.1 · 로그인: [S7-login.md](S7-login.md)
> 목업: [../mockups/saved-logged-out.png](../mockups/saved-logged-out.png) (로그인 전)
> 코드: iOS `Features/Saved/SavedView.swift`·`SavedViewModel.swift` · Android `feature/saved/SavedScreen.kt`·`SavedViewModel.kt`

## 목적
찜한 볼거리를 다시 찾게 한다. **저장은 계정에 한다**(v1.3) — 카카오/Apple로 로그인하면 기기를 바꿔도 남는다. 끝난 항목은 종료 후 90일까지 흐리게 보여주고, 그 뒤 서버가 정리한다.

## 데이터
- **로그인 후:** `GET /v1/me/saved`(스팟 스냅샷 포함, 끝난 항목은 `is_ended: true`) — `Authorization: Bearer <Supabase JWT>`. 저장 `PUT /v1/me/saved/{spot_id}`, 삭제 `DELETE /v1/me/saved/{spot_id}`.
- **마지막 응답을 기기에 캐시**한다(계정별). 화면에 들어오면 캐시로 바로 그리고, 뒤에서 다시 받아 바꾼다. 로그아웃·탈퇴 때 캐시를 지운다.
- 저장·삭제는 **낙관적 갱신**: 화면을 먼저 바꾸고 요청, 실패하면 되돌리고 토스트.
- 이전 버전의 "각 항목을 `GET /v1/spots/{id}`로 다시 받기"는 없앤다(서버 응답에 `is_ended`가 들어 있음).
- **로그인 전:** 목록을 보여주지 않는다. 이 기기에 이전 버전에서 저장한 항목(기기 로컬 저장)이 남아 있으면 개수만 안내한다(아래 "기기 저장 옮기기").

## 레이아웃 (위→아래)
1. **상단 바**: 큰 제목 `type.title1` **저장** (iOS large title, Android 일반 바 + 같은 글자 크기). 오른쪽 끝 글자 버튼 **편집**은 **로그인 상태이고 항목이 있을 때만**. 편집 중에는 **완료**. 설정 톱니는 없다(설정은 MY 탭, DESIGN §6.12).
2. 본문 — 상태별(아래 표).
3. **탭 바**: 주변 · 지도 · 저장(선택)

### 로그인 후 본문
1. **진행 중 섹션**: 섹션 제목 없음. `SpotCard` — 저장 시각(`saved_at`) 최신순. 메타 첫 줄 거리는 현재 위치를 알면 앱에서 계산, 모르면 장소명.
2. **끝난 볼거리 섹션** (종료 항목이 있을 때): 섹션 제목 `type.caption` `text.secondary` **끝난 볼거리 N** (위 `space.6`, 좌우 20) + 오른쪽 글자 버튼 **모두 지우기** → 종료 카드(불투명도 40% + `종료됨` 배지). 섹션 아래 안내 `type.caption` `text.secondary`: **끝난 지 90일이 지나면 자동으로 지워져요.**

### 로그인 전 본문 (`SignInPrompt`, 목업 참고)
DESIGN §6.7 상태 화면 모양을 그대로 쓴다(가운데 정렬, 위 `space.10`).
- 아이콘 `bookmark` 48 `gray500`
- 제목 `type.title2`: **로그인하면 저장할 수 있어요**
- 설명 `type.body` `text.secondary`: **저장한 볼거리를 어느 기기에서든 다시 볼 수 있어요.**
- 주 버튼(`size.button.md`, 잉크, `radius.sm`, 좌우 패딩 32): **로그인** → S7 시트(대기 동작 없음, 성공 후 이 화면이 목록으로 바뀜)
- 그 아래 `space.3` 글자 버튼 `TextButton` **주변 둘러보기** → 주변 탭
- 기기 로컬 저장이 남아 있으면(이전 버전 사용자) 설명을 바꾼다: **이 기기에 저장한 볼거리 N개가 있어요. 로그인하면 계정으로 옮겨 드려요.**
- 카카오·Apple 버튼을 이 화면에 직접 두지 않는다 — 브랜드 버튼은 S7 시트 한 곳에만(가이드 준수 지점을 한 곳으로).

| 세션 만료 (리프레시 실패) | 로그인 전 상태로 바뀌고 토스트 **다시 로그인해 주세요** |
| 편집 | 각 카드 왼쪽에 선택 원, 하단 바 **N개 지우기**(빨강 아님 — 잉크 주 버튼). 상단 **완료** |

## 기기 저장 옮기기 (첫 로그인 1회)
v1.3 이전 앱은 기기에만 저장했다. 그 항목을 잃지 않게 첫 로그인 때 계정으로 옮긴다(TECH-PLAN §4.1).
1. 로그인 성공 직후(어느 진입이든) 기기 로컬 저장 목록을 읽는다. 없으면 끝.
2. 각 항목 `PUT /v1/me/saved/{spot_id}`(동시 4개). 이미 계정에 있으면 서버가 그대로 둔다(멱등). 404(서버에서 정리된 볼거리)는 성공으로 친다.
3. 성공한 항목만 로컬에서 지운다. 실패한 항목은 남겨 두고 **다음 앱 실행 때 조용히 다시** 시도(토스트 없음).
4. 하나라도 옮겼으면 토스트 **기기에 저장했던 N개를 계정으로 옮겼어요** (N = 옮긴 개수, 404 제외). S7 저장 토스트와 겹치면 저장 토스트 다음에.
5. 옮기는 동안 S4는 첫 로딩 상태(스켈레톤), 끝나면 `GET /v1/me/saved` 결과로 그린다.
- 로그아웃해도 기기 로컬 저장은 다시 생기지 않는다(로그인 전 저장 버튼은 S7 시트를 띄우므로).

## 인터랙션
- 카드 탭 → S3 (종료 항목도 상세로 — 상세가 '종료됨'을 보여준다).
- iOS 왼쪽으로 밀기 / Android 길게 누르기 메뉴 → **삭제**. 삭제 후 토스트 **저장을 취소했어요** + 글자 버튼 **되돌리기**(4초, 누르면 다시 `PUT`).
- 삭제 실패 → 카드 되돌림 + 토스트 **지우지 못했어요. 잠시 후 다시 시도해 주세요.**
- 다른 화면에서 저장/저장 취소 실패 → 아이콘 되돌림 + 토스트 **저장하지 못했어요. 다시 눌러 주세요.**
- 끝난 볼거리 **모두 지우기** → 확인 대화상자 "끝난 볼거리 N개를 지울까요?" / **지우기** · **취소**.
- 로그인 전 화면 **로그인** → S7. 시트가 닫히면(취소) 그대로.

## 접근성
- 종료 카드: "종료됨, {title}, …". 불투명도를 낮춰도 배지 글자는 100%라 대비 유지.
- 스와이프 삭제는 스크린리더 사용자에게 사용자 지정 동작 "삭제"로도 제공.
- 로그인 전 화면: 제목 → 설명 → "로그인, 버튼, 로그인 창이 열려요" → "주변 둘러보기, 버튼".
- 옮기기 토스트는 스크린리더로 읽어준다(토스트 공통 규칙).
