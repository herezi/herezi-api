# S4 저장 목록

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN §8 P1 저장(찜), §9 S4, PRODUCT 원칙 3

## 목적
찜한 볼거리를 다시 찾게 한다. 가입 없이 기기에만 저장한다. 끝난 항목은 지우지 않고 흐리게 보여준다.

## 데이터
- 기기 로컬 저장소(iOS SwiftData/`UserDefaults` JSON, Android Room/DataStore)에 Spot 스냅샷 + 저장 시각.
- 화면에 들어올 때마다 각 항목을 `GET /v1/spots/{id}`로 다시 받아 `is_ended`·기간을 갱신(동시 4개). 404면 종료로 취급하고 스냅샷을 유지.

## 레이아웃 (위→아래)
1. **상단 바**: 큰 제목 `type.title1` **저장** (iOS large title, Android `LargeTopAppBar` 대신 일반 바 + 같은 글자 크기). 오른쪽 글자 버튼 **편집**(항목 있을 때만), 그 오른쪽 끝에 **설정** 톱니 아이콘 버튼(`gearshape` / `settings`, 라벨 "설정") → S6 push. 톱니는 빈 상태에서도 보이고, 편집 중에만 숨긴다(그때는 **완료**만). 이유는 DESIGN §6.12.
2. **진행 중 섹션**: 섹션 제목 없음. `SpotCard` — 저장 시각 최신순. 메타 첫 줄 거리는 현재 위치를 알면 앱에서 계산, 모르면 장소명.
3. **끝난 볼거리 섹션** (종료 항목이 있을 때): 섹션 제목 `type.caption` `text.secondary` **끝난 볼거리 N** (위 `space.6`, 좌우 20) → 종료 카드(불투명도 40% + `종료됨` 배지).
4. **탭 바**: 주변 · 지도 · 저장(선택)

## 상태
| 상태 | 모습 · 문구 |
|---|---|
| 빈 | 아이콘 `bookmark` · **저장한 볼거리가 없어요** · 마음에 드는 곳을 저장해 두면 여기에 모여요. · 버튼 **주변 둘러보기**(→ 주변 탭) |
| 데이터 있음 | 위 레이아웃. 갱신 중에는 스냅샷으로 바로 그리고 별도 로딩 표시 없음 |
| 갱신 오류 | 스냅샷 그대로, 표시 없음(조용히 실패). 다음 진입 때 재시도 |
| 편집 | 각 카드 왼쪽에 선택 원, 하단 바 **N개 지우기**(빨강 글자 아님 — 잉크 주 버튼). 상단 **완료** |

## 인터랙션
- 카드 탭 → S3 (종료 항목도 상세로 — 상세가 '종료됨'을 보여준다).
- iOS 왼쪽으로 밀기 / Android 길게 누르기 메뉴 → **삭제**. 삭제 후 토스트 **저장을 취소했어요** + 글자 버튼 **되돌리기**(4초).
- 끝난 볼거리 섹션 제목 오른쪽 글자 버튼 **모두 지우기** → 확인 대화상자 "끝난 볼거리 N개를 지울까요?" / **지우기** · **취소**.

## 접근성
- 종료 카드: "종료됨, {title}, …". 불투명도를 낮춰도 배지 글자는 100%라 대비 유지.
- 스와이프 삭제는 스크린리더 사용자에게 사용자 지정 동작 "삭제"로도 제공.
