# S5 검색

> 토큰·컴포넌트: [DESIGN.md](../DESIGN.md) · 기획: SERVICE-PLAN §8 P1 검색, §9 S5

> 진입: 홈(S1)·전체 목록(S1b)·지도(S2) 상단 바의 검색 아이콘. API: `GET /v1/spots?q=`(#28).

## 목적
"빛초롱", "성수 팝업"처럼 이름을 알고 찾는 사람을 위한 화면. 결과도 "지금 갈 수 있는 것"만.

## 레이아웃 (위→아래)
1. **검색 바** (상단, 좌우 20, 높이 44, `bg.secondary`, `radius.md`, 앞에 `magnifyingglass` 아이콘 `gray500`)
   - 힌트: **축제, 전시, 장소 이름으로 찾기**
   - 입력 중이면 오른쪽 지우기 버튼(`xmark.circle.fill` / `cancel`). 바 오른쪽 글자 버튼 **취소**(iOS) / 왼쪽 뒤로(Android).
   - 들어오면 바로 키보드가 올라온다.
2. **검색 전**: 최근 검색
   - 섹션 제목 `type.caption` `text.secondary` **최근 검색** + 오른쪽 글자 버튼 **전체 삭제**
   - 행: `clock` 아이콘 + 검색어 `type.body` + 오른쪽 `xmark` 지우기. 최대 10개, 기기 로컬.
3. **검색 후**: 기간 탭 없이 결과 수 줄 **'빛초롱' 검색 결과 3개** + `SpotCard` 목록(거리순, 현재 위치 기준 반경 20km).

## 상태
| 상태 | 모습 · 문구 |
|---|---|
| 최근 검색 없음 | 가운데 `type.body` `text.tertiary` **최근 검색이 없어요** |
| 로딩 | 스켈레톤 카드 5장 |
| 결과 있음 | 위 레이아웃 |
| 결과 없음 | 아이콘 `magnifyingglass` · **'{q}'에 맞는 볼거리가 없어요** · 지금 진행 중인 것만 찾아요. 다른 이름으로 찾아보세요. |
| 오류 | **불러오지 못했어요** · 잠시 후 다시 시도해 주세요. · 버튼 **다시 시도** |

## 인터랙션
- 키보드 검색(Return/IME 검색) 누르면 조회. 글자 입력마다 조회하지 않는다(M1).
- 2글자 미만이면 검색 안 함, 토스트 **두 글자 이상 입력해 주세요**.
- 최근 검색 탭 → 바로 조회. 결과 카드 탭 → S3.
- 카테고리·무료 필터는 M1 검색에 없다.

## 접근성
- 검색 바 라벨 "볼거리 검색". 결과가 나오면 결과 수를 알림.
- 최근 검색 지우기 버튼 라벨 "{검색어} 지우기".
