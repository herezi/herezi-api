# Herezi — 제품 스펙 (모든 레포의 단일 기준)

> 이 문서는 `herezi-api`, `herezi-ios`, `herezi-android` 세 레포가 공통으로 따르는 제품 기준이다.
> 앱 레포는 이 파일을 복사하지 말고 링크로 참조한다: https://github.com/herezi/herezi-api/blob/main/docs/product/PRODUCT.md

## 한 줄
앱을 열면 **위치만으로 "지금 내 주변에 뭐가 있는지"** 보여준다. 둘러보기는 가입·등록 없이 누구나, 저장할 때만 로그인(만 14세 이상).
위치는 기기 밖으로 나가지 않는다 — 서버는 지역 데이터 파일만 주고, 거리·근처·지도는 기기에서 계산한다.

## 문제
- "이번 주말 어디 가지?", "이 동네 지금 뭐 하지?"에 답하려면 네이버·인스타·지자체 사이트를 여러 군데 뒤져야 한다.
- 회원 제보형 서비스는 초기에 데이터가 없어서 죽는다(콜드스타트).

## 원칙
1. **입력 0**: 위치 허용만으로 첫 화면이 채워진다. 둘러보기는 나이 제한 없이 누구나. 저장(찜)만 카카오/Apple 로그인 필요(**만 14세 이상**, 로그인 시트에 확인 문구).
2. **공공 데이터 먼저**: 회원 제보 없이도 첫날부터 꽉 차 있어야 한다. 제보는 덤 레이어.
3. **"지금" 우선**: 오늘·이번 주말에 실제로 갈 수 있는 것만. 끝난 행사는 목록·지도·검색에 노출하지 않는다. 상세 조회는 끝난 행사도 `is_ended: true`로 돌려주고 앱은 '종료됨'으로 표시한다(찜 목록에서 흐리게). 끝난 항목은 종료 후 90일까지 보존한다.
4. **서울부터**: 데이터가 가장 풍부한 서울에서 검증 후 확장.
5. **위치 비전송** (2026-11-25 결정, #74): 앱은 사용자 좌표를 서버로 보내지 않는다. 앱이 `GET /v1/regions/{region}/spots`(지역 단위 전체 데이터, 현재 `seoul`)를 받아 두고 **거리 계산·근처 목록·지도 영역·정렬·검색·위치 이름(기기 지오코더)** 을 모두 기기에서 처리한다. 상세(`/v1/spots/{id}`)·저장(`/v1/me/*`)은 좌표 없이 서버를 쓴다. 좌표를 받는 API(`/v1/spots` 근처, `/v1/spots/map`, `/v1/geo/reverse`)는 폐기 예정.

## 카테고리 (`category` enum)
| 값 | 설명 |
|---|---|
| `nature` | 자연·계절 (벚꽃, 단풍, 핑크뮬리, 첫눈, 노을 명소) |
| `festival` | 축제·행사 (지역축제, 불꽃놀이, 야시장, 플리마켓) |
| `performance` | 공연 (콘서트, 뮤지컬, 무료공연, 버스킹) |
| `exhibition` | 전시 |
| `popup` | 팝업스토어·브랜드 행사 |
| `food` | 먹거리 (푸드트럭, 먹거리 장터) |
| `family` | 아이·가족 체험 |
| `pet` | 반려동물 행사 |
| `sports` | 스포츠 경기·마라톤 |

무료 여부는 카테고리가 아니라 `free=true` 필터로 조회한다.

## 데이터 소스 (M0에서 실사용 가능 여부 검증)
- 한국관광공사 TourAPI 4.0 (축제·행사) — data.go.kr
- KOPIS 공연예술통합전산망 (공연)
- 서울 열린데이터광장 문화행사 정보
- 문화포털 / 문화공공데이터광장 (전시·체험)
- 산림청·기상청 (개화·단풍 시기)
- 뉴스·보도자료 → GPT로 구조화 (팝업 등, 저작권·약관 확인 필수)

LLM은 **OpenAI GPT**를 사용한다 (정규화·요약·중복 병합).

## 마일스톤
- **M0 — 기반**: 레포 3개 하네스 세팅, CI, API 계약(`api/openapi.yaml`), 데이터 소스 실사.
- **M1 — 서울 MVP**: 수집기 2~3개 → DB(PostGIS) → 지역 데이터 파일(`GET /v1/regions/seoul/spots`) → 앱에서 근처 계산. 앱: 목록 + 지도 + 카테고리/기간 필터 + 상세 + 검색. 저장은 카카오/Apple 로그인.
- **M2 — 알림**: 관심 지역·카테고리 푸시 (로그인 계정에 기기 등록).
- **M3 — 회원 제보**: "지금 여기 이래요" 사진 제보, 확인 투표.

## 하지 않는 것 (M1)
댓글, 소셜, 서울 외 지역, 웹 버전.
