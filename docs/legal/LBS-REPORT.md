### 1.1 왜 '필요할 가능성이 높다'인가

| 쟁점 | 내용 | 상태 |
|---|---|---|
| 위치기반서비스사업 정의 | "위치정보를 이용한 서비스를 제공하는 것을 사업으로 영위하는 것"(법 제2조 제7호). 현재 위치로 주변 볼거리·거리·동네 이름을 보여주는 히어지는 문언상 해당 | 확인 [L1] |
| 위치정보 정의 | 이동성이 있는 물건 또는 개인의 특정 시간 장소 정보로서 전기통신설비 등을 이용해 측위된 것(제2조 제1호). 스마트폰 GPS 좌표가 해당 | 확인 [L1] |
| 신고 대상 범위 | 제9조 제1항: 위치기반서비스사업 중 **"개인위치정보를 대상으로 하지 아니하는 위치기반서비스사업은 제외"**. 즉 신고 대상은 **개인위치정보**를 다루는 경우뿐 | 확인 [L1] |
| 개인위치정보 정의 | 특정 개인의 위치정보. **"위치정보만으로는 특정 개인의 위치를 알 수 없는 경우에도 다른 정보와 용이하게 결합하여 특정 개인의 위치를 알 수 있는 것을 포함"**(제2조 제2호) | 확인 [L1] |
| 히어지가 개인위치정보를 다루나 | 이용자 기기 좌표가 요청마다 IP 주소와 함께 서버에 도착하고, 로그인 이용자는 계정(카카오/Apple)과 결합될 수 있다. 서버에 저장하지 않아도 '수집·이용'은 일어난다(요청 처리 중 이용). **결합 용이성 기준상 개인위치정보로 볼 여지가 크다** | 미확인(해석) |
| "저장 안 하면 면제" 조항 | 법·시행령에서 **저장하지 않는 서비스에 대한 면제 조항은 찾지 못함**. 저장 여부는 파기 의무(제23조) 이행의 문제로 다뤄진다 | 확인(조문에 없음) [L1] |
| 2024년 개정(사물위치정보 분리) | 현행법에 '개인위치정보를 대상으로 하지 아니하는' 위치정보사업 신고(제5조의2, "사물위치정보사업자") 및 위 제9조 제외 문구가 있다. **개정 연도가 2024인지는 확인 못함**(조문 개정 표기는 2018.4.17, 2021.10.19, 2025.10.1) | 일부 미확인 |
| 소상공인·1인 창조기업 특례 | 신고 없이 시작 가능하되 **사업 개시 1개월 이내 신고**해야 계속 가능(제9조의2) — 면제가 아니라 유예 | 확인 [L1][C2] |
| 기기 안에서만 위치를 쓰는 경우 | 센터 질의응답 게시판에 "위치를 기기 안에서만 쓰고 서버로 보내지 않는 지도 앱"의 신고 대상 여부 문의가 있으나 답변은 비공개 | 미확인 |
| 위치정보사업(수집) 등록 필요 여부 | 개인위치정보 대상 위치정보사업은 **등록**이며 법인 요건(제5조 제1항 제1호). 앱이 OS 위치를 읽어 자기 서비스에만 쓰는 경우 위치정보사업 등록까지 필요한지는 **공식 답을 찾지 못함**. 소규모 앱은 실무상 위치기반서비스사업 신고만 하는 것으로 알려져 있으나 출처 없음 | **미확인 — 사전검토 질문에 반드시 포함** |
| TourAPI 운영계정 | 활용신청 화면에 "위치기반서비스사업신고필증 미등록 시 반려될 수 있음" 안내(이슈 #60 본문, 사용자 확인) | 확인(사용자 화면) |

## 3. 신고 절차

### 3.1 누가 신고할 수 있나

| 항목 | 내용 | 상태 |
|---|---|---|
| 신고 자격 | 센터 안내: "사업자등록증 소지자로서 개인위치정보를 이용한 서비스를 제공하는 사업을 영위하는 사업자는 모두 가능" → 개인사업자 가능 | 확인 [C1] |
| 사업자등록 없는 개인 | 시행령 제9조 제3항·제10조 제4항: 수리기관이 **법인 등기사항증명서 또는 사업자등록증명**을 행정정보 공동이용으로 확인. 사업자등록 없는 개인을 위한 경로는 없음 | 확인 [L2] (→ 사업자등록 필수로 판단) |
| 법인 필요 여부 | 위치기반서비스사업 신고는 법인 요건 없음(법인 요건은 위치정보사업 **등록**에만) | 확인 [L1] 제5조·제9조 |

### 3.2 두 가지 경로

| | A. 일반 신고 (제9조) | B. 소상공인등 특례 (제9조의2) |
|---|---|---|
| 대상 | 누구나(사업자) | 소상공인 또는 1인 창조기업 |
| 시기 | 사업 **시작 전** 신고 | 신고 없이 시작 가능, **사업 개시일부터 1개월 이내** 신고 |
| 신고 사항 | 상호, 주된 사무소 소재지, 사업 종류, 위치정보시스템 포함 주요 설비 | 상호, 주된 사무소 소재지, 사업 종류 및 내용 |
| 첨부 서류 | ① 사업자 현황·사업 내용이 포함된 **사업계획서** ② **사업용 주요설비 내용과 설치 장소**를 확인할 수 있는 서류 ③ 법 제16조 **위치정보 보호조치를 증명하는 서류** | ① 소상공인확인서 또는 1인 창조기업 확인 서류 ② 사업 종류·내용 자료 |
| 출처 | 확인 [L1] 제9조, [L2] 시행령 제9조, [C1] | 확인 [L1] 제9조의2, [L2] 시행령 제10조, [C2] |
| 장점 | 신고필증(TourAPI 제출용) 확보가 명확 | 서류 가벼움 |
| 단점 | 사업계획서·보호조치 서류 작성 부담 | 소상공인 확인서 발급(신규 사업자 가능 시점) 미확인, **신고필증이 발급되는지·TourAPI가 인정하는지 미확인** |

- 소상공인: 상시근로자 10인 미만 소기업 등, 확인서는 중소기업현황정보시스템(sminfo.mss.go.kr). 1인 창조기업: 상시근로자 없이 1인 또는 5인 미만 공동사업자, 확인은 K-Startup. 확인 [C3]
- 1인 창조기업·소상공인 확인을 **사업자등록 직후** 받을 수 있는지: 미확인.
- 특례로 시작해도 소상공인등에 해당하지 않게 되면 1개월 이내 일반 신고 서류로 보완 신고. 확인 [L1] 제9조의2 제4항

**권장: A(일반 신고)를 출시 전에.** TourAPI 운영계정 전환에 필증이 필요하고, 특례 신고로 필증이 나오는지 확인되지 않았기 때문. B가 필증을 주고 TourAPI도 인정한다고 센터가 확인해 주면 B로 바꿔도 된다.
